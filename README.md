# parole-italiane

## Правила безопасных обновлений

- Изменения владельца хранятся в Supabase (`base_card_overrides`, `user_cards`, `user_topics`) и являются актуальными данными сайта.
- Перед изменением словаря нужно сверять эти таблицы; нельзя восстанавливать карточки или разделы из старой копии кода.
- Порядок существующих карточек в `worker/study-pack.json` менять нельзя: их номера используются прогрессом и сохранёнными правками.
- Публикации выполняются точечными микроправками без замены всего приложения или словаря.
